## 📄 Page Architecture

1. **`index.html`** — Home page with signboard positioning, editorial asymmetric hero, interactive five-discipline treatment index with live image switching, doctor profile composition, clinic gallery, consultation hours, and Google Maps embed.
2. **`about.html`** — In-depth profile of Dr. Shirly Annes.S, educational qualifications, medical registration, and the four tenets of Athmease biological care.
3. **`treatments.html`** — Comprehensive medical guide to all 5 signboard disciplines: Naturopathy, Acupuncture, Nutrition, Ozone, and Therapeutic Yoga.
4. **`contact.html`** — Action-oriented contact hub with direct Phone, WhatsApp, and Google Maps directions links, complete consultation timetable, and Plus Code context.

- **Brand Palette**:
  - Primary Deep Royal Navy: `#001c9d`
  - Clinical Midnight Navy: `#071233`
  - Accent Flow Cerulean: `#005cfc`
  - Soft Linen Off-White: `#faf9f5` / `#f4f1ea`
- **Typography**: Editorial serif (*Newsreader*) paired with high-legibility geometric sans (*Plus Jakarta Sans*).
- **Digital Signatures**: Flowing blue wave line vector motif derived directly from the physical signboard and logo; bespoke interactive treatment index; authentic photography.

## ⚡ Technical SEO & Standards

- **Semantic HTML5** with single H1 per page, descriptive alt text, and accessible focus states.

- **Open Graph Metadata** for rich social sharing previews.
- **`sitemap.xml`** and **`robots.txt`** included.
- **High-Performance WebP Images** with responsive aspect ratios and zero layout shift.
- Full `prefers-reduced-motion` compliance.

## 🚀 Running Locally

Serve the directory with any local static HTTP server:

```bash
# Python 3
python -m http.server 3030

# Node / npx
npx serve .
```

Visit `http://localhost:3030/` in your browser.
